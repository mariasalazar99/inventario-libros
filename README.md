# Inventario de Libros
Sistema de gestión de libros con login, registro de usuarios, protección de rutas y una gran galería de títulos que puedes encontrar (app de ejemplo, existe un catálogo limitado de libros).

# Tecnologías Aplicadas
1. HTML
2. CSS
3. Bootstrap
4. Javascript
5. Node.js
6. npm (express, dotenv, nodemon, sequelize, jsonwebtoken, bcrypt, ejs, y sqlite3).
